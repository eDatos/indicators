# Backend Specialist — INDICATORS-CORE

Module for statistical indicator business logic: indicators, indicator systems, dimensions, and calculation.

## Key versions

- **Hibernate**: 3.3.2.GA / **JPA**: 1.0 / **Spring**: 3.1.1.RELEASE / **JUnit**: 4.10 / **DBUnit**: 2.4.8

## Module Structure

```
indicators-core/
├── src/main/java/.../core/
│   ├── domain/           # JPA entities (Indicator, IndicatorsSystem, Dimension)
│   ├── repository/       # DAOs (Sculptor-generated)
│   ├── service/          # Service interfaces (Sculptor-generated)
│   ├── serviceimpl/      # Service implementations (manual)
│   ├── task/             # Quartz jobs
│   └── util/             # Utilities
├── src/main/resources/
│   └── btdesign/         # Sculptor model files
└── src/generated/java/   # Code generated by Sculptor — do not edit
```

## Strict Rules (NON-NEGOTIABLE)

### Sculptor / btdesign entities

Entities and service interfaces are **generated by Sculptor from `.btdesign` files** — never create them manually.

- Entity definitions: `src/main/resources/btdesign/indicators-core-model.btdesign`
- Generated code: `src/generated/java/.../domain/` and `src/generated/java/.../serviceapi/`
- Service **implementations** go manually in `src/main/java/.../serviceimpl/`

Sculptor btdesign example:
```
"Provides access to Indicators"
Service IndicatorsService {
    > @IndicatorRepository
    > @IndicatorsSystemRepository

    "Find indicator by code"
    @Indicator findIndicatorByCode(String code) throws MetamacException;
}
```

### No Java 8+

- NO lambdas, streams, method references, Optional, LocalDate/LocalDateTime
- Use traditional for loops and Joda Time
- Diamond operator `<>` **IS allowed** in core (unlike GWT modules):
  ```java
  Map<String, String> map = new LinkedHashMap<>();  // OK in core
  ```

### Spring Transactions

```java

    @Transactional(readOnly = true)

    @Transactional(propagation = Propagation.REQUIRES_NEW)
    public void independent() { ... }
}
```

## Service Implementation Pattern

```java
@Service
@Transactional
public class IndicatorsServiceImpl implements IndicatorsService {

    private static final Logger LOG = LoggerFactory.getLogger(IndicatorsServiceImpl.class);

    @Autowired
    private IndicatorRepository indicatorRepository;

    @Override
    public IndicatorDto createIndicator(IndicatorDto dto) throws MetamacException {
        // business logic
        Indicator created = indicatorRepository.save(indicator);
        return toDto(created);
    }

    @Override
    @Transactional(readOnly = true)
    public IndicatorDto retrieveIndicator(String code) throws MetamacException {
        Indicator indicator = indicatorRepository.findByCode(code);
        if (indicator == null) {
            throw new MetamacException("Indicator not found: " + code);
        }
        return toDto(indicator);
    }
}
```
